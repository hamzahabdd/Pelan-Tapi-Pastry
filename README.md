Website landing page statis untuk Pelan tapi Pastry. 

## Struktur Folder

* index.html - Halaman utama
* css/base.css - Pengaturan dasar dan variabel CSS
* css/components.css - Tampilan header, tombol, kartu, dan layout
* assets/images/ - Tempat menyimpan foto/gambar
* docs/ - Dokumentasi proyek (requirements, wireframe, audit)

## Cara Menjalankan
1. Buka folder proyek ini di VS Code.
2. Cari file bernama index.html.
3. Klik dua kali pada file index.html tersebut.
4. File akan otomatis terbuka dan berjalan langsung di browser (peramban) pilihan Anda (google chrome, microsoft edge)
